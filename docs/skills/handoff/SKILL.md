# 交接文档（Handoff）

## 目的与原则

- 一份文档要让"新 Agent 仅凭文档 + 引用的工件"即可继续干活，无需追问用户。
- 一切信息以真实证据为准：禁止捏造、猜测或含糊描述；无法确证的内容必须标注为假设或省略。
- 紧凑状态内联、冗长详情引用：关键证据、决策、陷阱必须内联；大段内容用路径/URL 引用，不复制。
- 不重复已存在于其他工件（PRD、计划、ADR、issue、commit、diff）中的内容，只引用。
- 敏感信息（API key、密码、PII）一律脱敏，只注明凭证存放位置与谁有权访问。
- 若用户传入 argument，视为下一会话的关注点，据此细化"下一步行动"。

## 保存位置与命名

- 项目已有既定交接目录（如 `docs/ce-tasks/`、仓库既有约定）→ 按该目录约定保存，保留追溯价值。
- 无既定目录 → 保存到 OS 临时目录，不污染工作区。
- 命名强制：`handoff_<YYYYMMDD_HHMM>_<session_slug>.md`。
- 禁止覆盖已有文件；同会话多轮时递增时间戳。

## 强制结构模板

**必填节**（缺失即不合格）：

1. 状态快照
2. 下一步行动
3. 工件清单

**有内容才写节**（无内容时整节删除，禁止留占位符）：

4. 未决问题与阻塞
5. 关键决策与已否决方案
6. 操作陷阱
7. 工作区脏状态
8. 已知限制与遗留
9. 建议技能

## 各节写法

### 1. 状态快照（必填）

- 一句话概括本次会话完成了什么（Session Summary）。
- 当前进度：阶段、完成度、最新提交 SHA。
- 与验收标准的关系：哪些验收项已过、哪些未过。
- 工具链/环境：语言、编译器或运行时版本、关键参数（如 `-std=c++26 -freflection -O2 -Wall`）、时间戳。

### 2. 下一步行动（必填）

- 1-3 件具体可执行的事，按顺序排列。
- 每条必须能直接通过"连续性校验"：含所需命令、入口、环境变量或凭证位置。
- 基于用户传入的 argument 细化；无 argument 时按会话自然走向给出建议。

### 3. 工件清单（必填）

- 每个工件给出：路径/URL + 成熟度（`draft` / `review` / `approved`）+ 一句话用途。
- 本地临时产物也列出（如临时目录下的提取文件），便于接手者定位。

### 4. 未决问题与阻塞（有内容才写）

必须分类标注，禁止只写"卡住了"：

- `waiting_on_user_input`：等用户拍板或提供信息。
- `pending_async_tasks`：异步任务在跑（轮次、任务 ID、预计完成条件）。
- `external_dependency`：等外部系统或他人。
- 每个阻塞注明"解阻塞后做什么"。

### 5. 关键决策与已否决方案

- 记录：决策 + 理由 + 否决了什么及为何。
- 防止新 Agent 重新争论已定事项（如"不建议采纳 MSVC 1D 函数指针表"）。

### 6. 操作陷阱

- 踩过的坑与绕法：API 字段名、命令行长度上限、需绕过的工具、易过期的补丁等。
- 格式："现象 + 正确做法"，让下一个不再重踩。

### 7. 工作区脏状态

- 未提交文件清单、已生效的本地 workaround、过期补丁（误加会破坏什么，如"原补丁已过期，误加会多出 `} // namespace literals`"）。

### 8. 已知限制与遗留

- 影响后续方法的约束，例如"storage construct 用 reinterpret_cast → engaged 态无法常量求值 → 测试只能走运行时"。

### 9. 建议技能

- 技能名 + 调用理由。
- 存在 waiting/pending 状态时，点名 `long-waits` 或 `self-driven`。

## 连续性校验（生成后必做）

写完自检："若我是新 Agent，仅凭本文档 + 引用的工件，能否不询问用户就执行下一步行动？"

- 对"下一步行动"逐条核对：命令、入口、环境变量、凭证位置是否齐备。
- 失败 → 补全 → 重检；未通过不算完成。
- 关键交接可升级为真子代理试读：让一个全新 agent 读本文档并报告能否开工（opt-in）。

## 完成清单

```
[ ] 状态快照含进度 / 提交 SHA / 工具链
[ ] 下一步行动逐条可通过连续性校验
[ ] 工件清单含路径 + 成熟度
[ ] 阻塞已分类（waiting_on_user_input / pending_async_tasks / external_dependency）
[ ] 决策 / 陷阱 / 脏状态 / 遗留按需记录，无占位符
[ ] 敏感信息已脱敏
[ ] 未复制工件中已有内容
[ ] 文件名含时间戳且未覆盖旧文件
```
