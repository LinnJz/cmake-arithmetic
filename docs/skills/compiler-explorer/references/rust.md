## 可设置参数（userArguments）参考

> 整理自 https://doc.rust-lang.org/rustc/command-line-arguments.html （2026-08-11）。参数直接传给 rustc。

**优化**: `-O`（等价 `-C opt-level=3`）、`-C opt-level=0..3`、`-C opt-level=s|z`（体积/速度优先）、`-C target-cpu=native`、`-C lto=fat|thin|off`、`-C codegen-units=N`、`-C panic=abort|unwind`、`-C debuginfo`（-C 完整清单见 rustc book 的 codegen-options 页）
**语言版本/edition**: `--edition 2015|2018|2021|2024`；注意旧 rustc 只支持旧 edition——2018 需 ≥1.31、2021 需 ≥1.56、2024 需 ≥1.85，本实例 r100~r130 等只接受 2015
**警告/诊断**: `-A`/`-W`/`-D`/`-F` 设置 lint 级别（按命令行顺序生效）、`-D warnings`、`--deny unsafe_code`、`--force-warn <lint>`、`--cap-lints`、`--error-format=human|json|short`、`--color`、`--remap-path-prefix`
**特殊功能**: `--test`（生成测试 harness）、`--cfg 'feature="x"'`（条件编译）、`--check-cfg 'cfg(...)'`、`--crate-type lib|rlib|staticlib|dylib|cdylib|bin|proc-macro`、`-g`（= `-C debuginfo=2`）、`--emit=asm|llvm-ir|llvm-bc|mir|obj`（`--emit=asm=-` 输出到 stdout）、`-o`/`--out-dir`、`--crate-name`、`-L <搜索路径>`、`-l <原生库>`、`--extern`、`--target <三元组>`、`--sysroot`
**nightly 专属**: `-Z` 不稳定标志（如 `-Z time-passes`、`-Z sanitizer=address`）仅 nightly 接受；本实例的 `nightly`、`beta` 编译器可用，其他稳定版 rustc 会报错
**常用组合**:
- 严格: `-O -D warnings --edition 2021`
- 性能: `-O -C target-cpu=native -C lto=thin`
- 体积: `-O -C opt-level=s -C codegen-units=1`
- 测试: `--test`
- 汇编: `--emit=asm`
- LLVM IR: `--emit=llvm-ir`
