## 可设置参数（userArguments）参考

> 整理自权威文档（见各子节来源），2026-08-11。这些参数放在请求体 `options.userArguments` 里。

### GCC（gcc 系编译器，如 g121/g122 等）

来源: https://gcc.gnu.org/onlinedocs/gcc/Option-Summary.html

**优化**

| 参数 | 含义 |
|----|----|
| `-O0` | 关闭全部优化（多数编译器的默认值） |
| `-O1` | 基础优化：合理体积与优化幅度，编译最快 |
| `-O2` | 常用优化档（不含以空间换时间的项），日常推荐 |
| `-O3` | 更强优化（含内联、自动向量化等），可能增大代码体积 |
| `-Os` | 针对代码体积优化 |
| `-Ofast` | `-O3` + `-ffast-math` 等效，可能违反 IEEE/ISO 语义 |
| `-Og` | 保持良好调试体验的优化级别（与 `-g` 搭配） |
| `-Oz` | 极致体积优化（GCC 12+ / Clang） |
| `-march=native` | 针对宿主 CPU 生成指令（CE 服务器为 x86-64） |
| `-march=x86-64-v3` | 按微架构级别 v3（AVX2/BMI 等）生成指令 |
| `-mtune=cpu-type` | 微调目标 CPU（如 `-mtune=skylake`），不改指令集 |
| `-mavx2` / `-msse4.2` / `-mavx512f` / `-mfma` / `-maes` / `-mbmi2` | 单独启用具体 ISA 扩展 |

**语言/标准版本**

| 参数 | 含义 |
|----|----|
| `-std=c11` | C11 标准 |
| `-std=c17` | C17 标准（GCC 默认） |
| `-std=c23` | C23 标准（需 gcc 13+） |
| `-std=gnu11` / `gnu17` / `gnu23` | 相应标准的 GNU 扩展变体 |
| `-std=c++98`/`c++11`/`c++14`/`c++17`/`c++20`/`c++23`/`c++26` | C++ 标准版本（c++20 需 gcc 10+；c++23 需 gcc 13+；c++26 需 gcc 15+） |
| `-std=gnu++98`…`gnu++26` | C++ 标准的 GNU 扩展变体（GCC 默认即 gnu 变体） |

**警告与诊断**

| 参数 | 含义 |
|----|----|
| `-Wall` | 启用常用警告集合 |
| `-Wextra` | 追加更多警告，常与 `-Wall` 并用 |
| `-Wpedantic` | 对非 ISO 标准扩展发出警告 |
| `-Werror` | 所有警告视为错误 |
| `-Wconversion` | 隐式转换可能改变值/符号时警告 |
| `-Wshadow` | 变量遮蔽警告 |
| `-Wnull-dereference` | 潜在空指针解引用警告 |
| `-w` | 关闭全部警告 |
| `-fmax-errors=n` | 达到 n 个错误后停止 |

**编译特殊设置**

| 参数 | 含义 |
|----|----|
| `-fsanitize=address` | AddressSanitizer（内存错误检测） |
| `-fsanitize=undefined` | UBSan（未定义行为检测；可 `-fsanitize=address,undefined` 联用） |
| `-fsanitize=thread` | ThreadSanitizer（数据竞争检测） |
| `-flto` | 链接时优化（多编译单元场景生效） |
| `-fno-exceptions` | 禁用 C++ 异常 |
| `-fno-rtti` | 禁用 RTTI（dynamic_cast/typeid 不可用） |
| `-g` | 生成调试信息（配合 ASan 有更好栈回溯） |
| `-pthread` | 启用线程宏并链接 pthread |
| `-static` | 静态链接 |
| `-D macro[=value]` | 定义预处理器宏 |
| `-U macro` | 取消宏定义 |
| `-I dir` / `-isystem dir` | 追加头文件搜索目录 |

### Clang（clang 全系 / clang-trunk）

来源: https://clang.llvm.org/docs/ClangCommandLineReference.html、https://clang.llvm.org/docs/UsersManual.html

Clang 兼容绝大部分 GCC 参数（见上节），以下是差异与 Clang 独有参数：

| 参数 | 含义 |
|----|----|
| `-O0`…`-Oz`、`-march=native`、`-mavx2` 等 | 与 GCC 语义一致 |
| `-std=c2y` | C 下一版标准草稿（clang-trunk） |
| `-stdlib=libc++` | 选用 LLVM 官方 C++ 标准库（GCC 默认 libstdc++） |
| `-fmodules` | 启用 Clang 模块（加速头文件处理） |
| `-fcoroutines-ts` | 启用协程 TS（旧版 clang；现代代码直接用 C++20 协程） |
| `-ftime-trace` | 输出 Chrome tracing 格式编译耗时 JSON |
| `-Xclang <arg>` | 直接向 Clang 前端透传参数 |
| `-fexperimental-new-pass-manager` | 强制新版 pass 管理器（仅 clang ≤15 需要；16+ 默认并已删除） |
| `-Weverything` | 开启所有诊断（常与 `-Wno-…` 组合减噪） |
| `-fno-omit-frame-pointer` | 保留栈帧指针（ASan 完整回溯） |

### clang-cl（clang-cl1810、clang-cl22 等，MSVC 兼容模式）

来源: https://clang.llvm.org/docs/UsersManual.html#clang-cl (Command Line Options)

! 注意：clang-cl 使用 MSVC 风格 `/选项` 语法（也接受 `-` 前缀），而非 GCC 风格。

| 参数 | 含义 |
|----|----|
| `/O2` | 优化速度（约当 `-O2`） |
| `/O1` | 优化体积 |
| `/Od` | 禁用优化 |
| `/Os` | 体积优先（约当 clang `-Os`） |
| `/Ox` | 已弃用，等同 `/O2` |
| `/std:c++14` / `c++17` / `c++20` / `c++23preview` / `c++26preview` / `c++latest` | C++ 标准版本 |
| `/std:c11` / `/std:c17` | C 标准版本 |
| `/EHsc` | C++ 异常处理模型（extern "C" 假定不抛异常） |
| `/GR` / `/GR-` | 启用/禁用 RTTI |
| `/W4` | 启用 `-Wall`+`-Wextra` 级别警告 |
| `/Wall` | 启用全部警告（`-Weverything`） |
| `/WX` | 警告视为错误 |
| `/MD` / `/MDd` | 动态链接 CRT（d=debug） |
| `/MT` / `/MTd` | 静态链接 CRT |
| `/D <macro>` / `/I <dir>` | 宏定义 / 头文件路径 |
| `/Fe<name>` | 指定输出可执行文件 |
| `/clang:<arg>` | 透传给 clang 驱动（驱动层等价物） |
| `/fsanitize=address` | clang-cl 支持 ASan |

### MSVC cl（cl19_*_exwine，v19.0/19.10/19.14，运行于 WINE）

来源: https://learn.microsoft.com/en-us/cpp/build/reference/compiler-options、https://learn.microsoft.com/zh-cn/cpp/build/reference/compiler-options-listed-by-category?view=msvc-170、https://learn.microsoft.com/en-us/cpp/build/reference/compiler-options-listed-alphabetically?view=msvc-170

! 重要：本实例 MSVC 最老到 v19.14（VS 2017 时代），新标准支持有限。

| 参数 | 含义 |
|----|----|
| `/O2` | 优化速度（release 默认） |
| `/O1` | 优化体积 |
| `/Od` | 禁用优化（debug 默认） |
| `/Ox` | 最大优化（已弃用，约等 `/O2`） |
| `/Os` | 体积优先 |
| `/std:c++14` | C++14（v19.10 时代默认） |
| `/std:c++17` | C++17（v19.11+ 可用） |
| ⚠️ `/std:c++20` | 本实例不支持（v19.14 及更早无 C++20）；新标准代码请用 clang-cl 或 GCC |
| `/EHsc` | C++ 异常处理（推荐基础项） |
| `/GR` | 启用 RTTI（默认开） |
| `/Zc:preprocessor` | 符合标准的预处理器（19.14 需显式开启） |
| `/W4` | 高警告级别（默认 `/W1`；实战常用 `/W3`/`/W4`） |
| `/Wall` | 全部警告（含系统头，噪音大） |
| `/WX` | 警告视为错误 |
| `/D macro[=value]` | 定义宏 |
| `/I dir` | 头文件搜索路径 |
| `/MD` / `/MT` | CRT 动态/静态链接（debug 用 `/MDd`、`/MTd`） |
| `/Fe<name>` | 指定输出文件名 |
| `/D_CRT_SECURE_NO_WARNINGS` | 抑制 scanf/strcpy 等 CRT 安全弃用警告 |

### 常用组合示例

| 用途 | 建议参数 |
|----|----|
| 快速原型 | `-O2 -std=c++20 -Wall -Wextra` |
| 严格检查 | `-O2 -std=c++23 -Wall -Wextra -Wpedantic -Werror` |
| 调试 + ASan | `-O1 -g -fsanitize=address -fno-omit-frame-pointer` |
| 极致性能 | `-O3 -march=native -flto` |
| MSVC 对标 | `/O2 /std:c++17 /EHsc /W4`（clang-cl / MSVC 语法） |

| 配置 | 编译参数 | 链接参数 |
|----|----|----|
| Debug | `-g3 -ggdb -O0 -fno-omit-frame-pointer -fno-inline -fno-optimize-sibling-calls -fno-common` | `-g` |
| Release | `-O3 -flto -fmerge-constants -finline-functions -funroll-loops -fomit-frame-pointer -ffunction-sections -fno-math-errno` | `-flto -s -Wl,--gc-sections` |
| RelWithDebInfo | `-O2 -g -fno-omit-frame-pointer -flto -funroll-loops -fmerge-constants -finline-functions-called-once -ffunction-sections` | `-flto -g -Wl,--gc-sections` |

**链接器通用**：`-rdynamic`（导出全部符号，dlopen 插件/完整 backtrace 需要；MinGW 用 `-Wl,--export-all-symbols`）、`-Wl,-z,stack-size=4194304`（4 MiB 栈）。

**Sanitizers（GCC/Clang）**：`-fsanitize=address,undefined -fno-omit-frame-pointer`（**编译与链接都要加**；仅 GCC/Clang 支持）。

**CE 提醒**：`-march=native/-mtune=native` 在 CE 上解析为宿主机 x86-64（≠ 本地 CPU）；`/Zi` 等 PDB 项远程无产物意义；MSVC 的 `/std:c++latest`、`/openmp:experimental` 等新特性本实例不可用。
