# 领域配置：健康 / 医疗

## 验证对象

疾病认知、药物用法、剂量、治疗方案、营养建议、健康数据。**此类内容错误可能危害健康，核查标准最严格。**

## 触发示例

- "验证这篇健康科普" / "这个用药建议对吗"
- "核查这个健康数据"

## 断言分类体系

| 类别 | 说明 | 示例问题 |
|------|------|---------|
| `Dose` | 剂量、用法、疗程、适应症/禁忌 | "成人布洛芬单次剂量上限真的是 800mg 吗？" |
| `Treatment` | 治疗方案、疗效声称 | "该疗法是否有指南或 RCT 支持？" |
| `Fact` | 疾病机制、症状、流行病学数据 | "高血压诊断标准在 2024 中国指南中是多少？" |
| `Safety` | 风险、副作用、相互作用、禁忌 | "该药物与酒精同服是否明确禁忌？" |
| `Currency` | 指南/标准版本时效 | "该说法是否符合最新临床指南？" |
| `Gap` | 遗漏警示、适用人群限制 | "是否遗漏了孕妇/儿童禁忌？" |

## 权威来源白名单（按优先级）

1. 官方卫生机构（WHO、国家卫健委、FDA、NMPA、CDC、EMA）
2. 权威临床指南（NCCN、ESC、AHA、中华医学会指南、UpToDate）
3. 同行评审医学期刊（NEJM、Lancet、BMJ、JAMA、专业期刊）
4. 药品说明书原文（NMPA/FDA 官网的 label）

## 绝对禁止引用

- 任何养生号、营销号、未具名医学科普、论坛经验贴
- 无指南/文献支撑的"偏方""秘方"内容

## 搜索偏好

- **语言**：中英双语；中国语境优先查 NMPA/卫健委/中华医学会
- **时效**：以最新指南与说明书为准，标注年份
- **关键词策略**：`<药物名> 说明书 site:gov.cn` / `<病种> guideline 2026`

## 修复策略备注

- 剂量/用法与说明书不一致 → 以说明书原文为准并标注
- 缺乏指南支持的疗效声称 → 标注"无权威指南支持，属个人经验"
- 涉及处方药的具体使用，倾向标 ❓ 并提示就医
- 所有健康相关结论建议附带"请以医生/药师意见为准"式提示（由用户决定是否保留）
