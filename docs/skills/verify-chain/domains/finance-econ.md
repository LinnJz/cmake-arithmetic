# 领域配置：财经 / 经济数据

## 验证对象

宏观经济指标、统计数据、市场数据、投资观点所引用的事实、政策信息、监管规则。

## 触发示例

- "验证这个经济数据" / "查查这个 GDP 增速对不对"
- "核查这篇财经文章的数据来源"

## 断言分类体系

| 类别 | 说明 | 示例问题 |
|------|------|---------|
| `Data` | 宏观/行业/企业数据 | "中国 2025 年 GDP 增速官方公布值是多少？" |
| `Statistic` | 统计口径、基期、统计方法 | "该失业率是城镇调查失业率还是登记失业率？" |
| `Policy` | 政策、监管规则、利率/准备金等 | "当前 LPR 是否仍是 3.0%？" |
| `Source` | 数据来源与发布方是否真实 | "该数据是否真的出自国家统计局？" |
| `Currency` | 数据时效 | "该数据是 2024 年还是 2025 年的？" |
| `Gap` | 遗漏口径、语境、风险提示 | "是否遗漏了数据口径不一致的说明？" |

## 权威来源白名单（按优先级）

1. 官方统计机构（国家统计局、央行、财政部、海关总署、美联储、ECB 等）
2. 国际机构（IMF、世界银行、OECD、UN）
3. 交易所与监管机构（沪深交易所、证监会、SEC、交易所官方数据）
4. 一手上市公司公告、财报
5. 权威财经媒体 —— 只作为线索，最终以原始数据为准

## 绝对禁止引用

- 无出处的行情截图、财经自媒体、荐股内容、内容农场
- 转载的"据传""知情人士透露"类无主信息

## 搜索偏好

- **语言**：中国数据查中文官方源；全球数据查英文官方源
- **时效**：标注数据所属期（季度/年度）；以官方最新公布为准
- **关键词策略**：`<指标> <年份> site:stats.gov.cn` / `<指标> release <year> <agency>`

## 修复策略备注

- 数据必须标注：**发布机构 + 指标名 + 统计口径 + 所属期间**
- 无法定位原始发布方的数据 → 标 ❓ 并删除或改写为"据 xxx 报道"
- 投资观点（"后市看涨"）属主观判断，不核查内容但需标注为观点
