# 领域配置：工具使用文档

## 验证对象

命令语法、参数名、选项行为、配置文件、环境变量、快捷键、界面操作步骤。

## 触发示例

- "验证这篇使用教程" / "这个参数能这么用吗"
- "这份操作手册步骤对吗"

## 断言分类体系

| 类别 | 说明 | 示例问题 |
|------|------|---------|
| `Command` | 命令语法、参数名、组合用法 | "`git reset --soft HEAD~1` 会不会丢工作区改动？" |
| `Option` | 选项/标志的行为、默认值 | "`tar -z` 是否真的等价于 `--gzip`？" |
| `Config` | 配置文件格式、字段、生效路径 | "`.npmrc` 中 `registry` 字段是否支持该写法？" |
| `Env` | 环境变量、路径、平台差异 | "`JAVA_HOME` 缺失时该工具行为是否如文所述？" |
| `Step` | 操作步骤的顺序与结果 | "按此步骤操作是否会得到文中结果？" |
| `Gap` | 遗漏平台差异、权限前提、破坏性影响 | "是否遗漏了 macOS 与 Linux 的差异？" |

## 权威来源白名单（按优先级）

1. 官方 man page / `--help` / 官方文档站
2. 官方仓库源码与 Release Notes
3. 官方教程/官方 blog（维护者署名）
4. 高票问答（Stack Overflow）—— 交叉参考

## 绝对禁止引用

- 个人博客、内容农场转载、旧版本教程（未标注版本）
- AI 生成的工具教程站

## 搜索偏好

- **语言**：技术类默认英文；中文工具的官方中文文档可用
- **时效**：以当前稳定版为准；标注版本
- **关键词策略**：`<工具名> <参数> man page` / `<工具名> changelog`

## 修复策略备注

- 实测优先：若环境可用，鼓励用 `--help`/`man` 实测后下结论
- 平台差异必须标注（Windows/Linux/macOS）
- 破坏性命令（`rm -rf`、`DROP TABLE`）需提示风险
