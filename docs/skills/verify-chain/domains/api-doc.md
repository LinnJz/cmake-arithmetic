# 领域配置：API / 库文档

## 验证对象

函数签名、参数行为、返回类型、默认值、版本兼容性、弃用状态、异常行为、依赖关系。

## 触发示例

- "验证这份 API 文档" / "查查这个函数的参数行为"
- "这个库在 v2.x 里还有这个函数吗"

## 断言分类体系

| 类别 | 说明 | 示例问题 |
|------|------|---------|
| `Signature` | 函数签名、参数名、参数顺序、返回类型 | "`HttpClient.Timeout` 的默认值是否真的是 100 秒？" |
| `Behavior` | API 实际行为、语义、边界情况 | "传 `null` 时该函数是抛异常还是返回 null？" |
| `Default` | 默认值、默认配置 | "该方法的默认超时是多少？" |
| `VersionCompat` | 版本兼容、弃用/移除、破坏性变更 | "该方法在 v5.0 是否被移除？替代方案是什么？" |
| `ErrorHandling` | 异常类型、错误码、重试语义 | "请求失败时返回什么错误码？" |
| `Gap` | 遗漏的依赖前提、环境限制 | "文档是否遗漏了该 API 依赖的运行时版本？" |

## 权威来源白名单（按优先级）

1. 项目官方 API Reference / 官方文档站
2. 官方 GitHub 仓库源码（类型定义、实现源码、CHANGELOG、Release Notes）
3. 官方 migration guide / deprecation 公告
4. RFC/提案、维护者署名的官方 blog
5. Stack Overflow 高票 —— 仅交叉参考

## 绝对禁止引用

- 三方聚合文档站、AI 生成的文档总结站
- 未署名转载、个人博客

## 搜索偏好

- **语言**：跟随项目官方语言（多数英文）；中文项目可用中文
- **时效**：以最新稳定版为准，标注历史版本差异
- **关键词策略**：`<包名> <API名> reference` / `<包名> changelog` / `<包名> deprecated`

## 修复策略备注

- 涉及弃用/移除的，补充"自 vX.Y 起废弃，替代为 Z"
- 默认值变更标注版本
