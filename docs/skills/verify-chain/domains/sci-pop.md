# 领域配置：科普 / 知识性内容

## 验证对象

科学事实、数据、统计、因果陈述、专家共识、历史事实、地理/天文/生物等知识性结论。

## 触发示例

- "验证这篇科普文章" / "这个说法科学吗"

## 断言分类体系

| 类别 | 说明 | 示例问题 |
|------|------|---------|
| `Data` | 具体数值、统计、测量结果 | "地球到月球平均距离真的是 38.4 万公里？" |
| `Fact` | 可查证的科学/历史事实 | "元素周期表 119 号元素是否已合成？" |
| `CausalClaim` | 因果关系、机制解释 | "'X 导致 Y' 是否有同行评审证据？" |
| `Consensus` | 专家共识、主流观点 | "科学界是否公认 XXX？" |
| `Currency` | 知识时效（科学结论可能被推翻） | "该结论在 2026 年是否仍被学界接受？" |
| `Gap` | 遗漏反例、争议、适用范围 | "是否遗漏了该结论不成立的条件？" |

## 权威来源白名单（按优先级）

1. 学术论文、同行评审期刊（Nature、Science、Cell 等；预印本需标注）
2. 官方科研机构（中科院、NASA、ESA、CERN、NIH 等）
3. 政府官方部门（统计局、疾控、气象局）
4. 专业百科全书（Britannica、Wikipedia 高质量条目）—— 交叉参考
5. 权威科普媒体（科学美国人、Nature News、科普中国）—— 作入口，非最终依据

## 绝对禁止引用

- 营销软文、伪科学内容、养生自媒体
- 无原始出处和发布日期的二手数据

## 搜索偏好

- **语言**：中英双语交叉验证
- **时效**：以最新研究/最新发布为准，标注数据年份
- **关键词策略**：优先搜一手来源（论文标题/机构名），而非转述

## 修复策略备注

- 数据必须补"机构 + 年份 + 出处"
- 因果类断言若无强证据，改为"有研究表明/尚存争议"并标 ❓
