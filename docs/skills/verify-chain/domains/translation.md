# 领域配置：翻译稿

## 验证对象

译文是否忠实原文、是否引入事实性错误、术语一致性、数字/专名/日期是否错译、技术/法律/医学等专业表述是否准确。

## 触发示例

- "核查这版译文" / "译文有没有错译"
- "验证翻译中的事实错误"

## 断言分类体系

| 类别 | 说明 | 示例问题 |
|------|------|---------|
| `Factual` | 译文是否引入与原文不一致的事实/数字 | "原文 15 km 译成了 150 km？" |
| `Fidelity` | 忠实度：漏译、增译、曲解原意 | "译文是否丢失了原文的限定条件？" |
| `Term` | 术语是否与领域权威译法一致 | "'load balancer' 是否应译为 '负载均衡器'？" |
| `ProperNoun` | 专名/人名/机构名/产品名拼写 | "'WHO' 是否误译为 '世界银行'？" |
| `Technical` | 专业技术表述是否符合行业规范 | "法律条款翻译是否保留条款编号？" |
| `Currency` | 涉及时效的事实（数据、法规、版本） | "译文中的年份是否过时？" |

## 权威来源白名单（按优先级）

1. **原文**（终审基准：事实一致性以原文为准）
2. 领域权威：术语表（ISO、国家标准术语表）、专业词典
3. 官方机构/公司官方中文译名（官网、官方公众号）
4. 领域权威来源（与技术文章同源：官方文档、法规、期刊）

## 绝对禁止引用

- 机器翻译作为"纠正依据"（可用作提示线索，不可作为终审依据）
- 来源不明的"标准译法"（需可溯源）

## 搜索偏好

- **语言**：双语对照；术语用中英 + 领域词典
- **时效**：涉及法规/数据/版本时按对应领域规则
- **关键词策略**：`<专名> 官方译名` / `<术语> 术语表 规范`

## 修复策略备注

- 事实/数字错译 → 按原文修正并标注
- 术语不一致 → 全文统一为权威译法
- 无法确证官方译名的专名 → 保留原文并加注，标 ❓
- 只改译文，不改原文
