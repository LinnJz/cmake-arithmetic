# 领域配置：合规 / 法规 / 安全

## 验证对象

法规条文引用、标准编号与版本、生效/废止状态、监管要求、安全配置、CVE 引用、GDPR/等保/ISO 等合规断言。

## 触发示例

- "验证这份合规文档" / "这条法规还有效吗"
- "引用的 ISO 标准版本对吗"

## 断言分类体系

| 类别 | 说明 | 示例问题 |
|------|------|---------|
| `Citation` | 法条/标准编号与内容是否对应 | "《数据安全法》第 21 条内容是否确如所述？" |
| `Status` | 生效/废止/修订状态 | "《个人信息保护法》是否仍现行有效？" |
| `Version` | 标准版本号与发布日期 | "引用的是 ISO 27001:2022 还是 2013？" |
| `Requirement` | 合规要求内容与范围 | "等保 2.0 三级是否要求该安全控制项？" |
| `Security` | 安全配置、漏洞编号（CVE） | "CVE-2024-3400 的受影响版本范围是否准确？" |
| `Gap` | 遗漏适用例外、期限、责任条款 | "是否遗漏了数据出境的申报义务？" |

## 权威来源白名单（按优先级）

1. 官方法规库（全国人大网、中国政府网、国家法律法规数据库）
2. 监管机构官网（网信办、工信部、证监会、监管部门公告）
3. 标准组织官方（ISO、国家标准全文公开系统、IETF）
4. CVE 库（NVD、CNVD）、安全厂商官方公告 —— 交叉参考
5. 法院判例、官方司法解释

## 绝对禁止引用

- 内容农场整理的"法规解读"（无原文对照）
- 过时的非官方转载
- 任何无编号、无生效日期的引用

## 搜索偏好

- **语言**：法规原文中文；国际标准英文官方源
- **时效**：**只认现行有效版本**；引用历史版本必须标注"已修订"
- **关键词策略**：`<法规名> 现行有效 全文 site:gov.cn` / `<标准号> 国家标准全文公开系统`

## 修复策略备注

- 法条引用 → 修正编号/内容并标注"现行有效 + 施行日期"
- 已废止/修订 → 标注现行版本及变更要点
- 无法核实效力的引用 → 标 ❓ 并提示"引用前请到官方库复核"
- 合规内容只做事实纠正，不提供法律意见
