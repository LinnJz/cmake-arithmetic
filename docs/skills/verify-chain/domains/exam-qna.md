# 领域配置：面试 / 考试题库

## 验证对象

题目与答案的正确性、解析的推导过程、标准答案一致性、过时题目。

## 触发示例

- "验证这道面试题的答案" / "这套题库答案对吗"
- "这个解析过程有没有问题"

## 断言分类体系

| 类别 | 说明 | 示例问题 |
|------|------|---------|
| `Answer` | 答案本身是否正确 | "栈和队列的 FIFO/LIFO 描述是否写反了？" |
| `Reasoning` | 解析/推导过程是否正确 | "该时间复杂度的推导是否成立？" |
| `Currency` | 题目/答案是否过时（语言版本、法规、技术栈） | "该 Go 并发答案是否符合当前版本语义？" |
| `Distractor` | 干扰选项是否确为错误选项 | "选项 C 是否真的错误？" |
| `Gap` | 答案是否遗漏重要边界/前提 | "答案是否遗漏了空指针场景？" |

## 权威来源白名单（按优先级）

1. 官方题解/官方样题（考试机构、认证官方 mock）
2. 标准与规范原文（语言规范、RFC、法律条文）
3. 权威教材与官方文档（作为答案依据）
4. 高票社区共识（Stack Overflow、官方 FAQ）—— 交叉参考

## 绝对禁止引用

- 无出处的"题库答案"网页（常常互相抄且错）
- 内容农场、SEO 刷题站

## 搜索偏好

- **语言**：跟随题目语言
- **时效**：标注题目基于的版本/年份
- **关键词策略**：`<题目核心词> <语言/科目> official documentation`

## 修复策略备注

- 答案错误 → 给出正确选项 + 权威依据
- 题目本身过时 → 标注"该知识点已随 vX 变更"，补充新答案
- 多答案争议题 → 列出双方依据，标 ❓ 供用户决定
