# AI Slop 审查清单

审查指定代码中的 AI 生成 slop 模式。

**目标：** 用户指定的代码/文件，或当前 git diff。
**输出格式：** 按类别分组，每条给出文件路径、行号、模式名、简要说明、建议修复。**不直接改代码**——只报告发现项，由用户决定改什么。

**严重度参考：** 下列模式大多归"轻微/重要"，**不默认致命**。例外：防御式写法实际掩盖了错误（如吞异常导致数据损坏、伪造默认值污染数据）时按实际影响升级。

## A. 防御式编程（10 条）

> 背景：AI 编码助手系统性过度生产防御式代码——训练数据偏向 Web/App 代码（那里优雅降级是正确的），RLHF 又强化了"崩溃比静默错误更糟"的惩罚。结果：代码吞错误、伪造数据、静默失败而非快速失败。
> **Fail-fast 原则：** 内部错误应立即大声崩溃。快速失败的系统反而故障更少，因为系统对自己的问题诚实。
> **防御何时正确：** 系统边界处理外部输入（API、表单、文件上传）时。内部代码应信任契约，违反即崩溃。

| # | 反模式 | 错误示例 | 正确做法 |
|---|--------|---------|---------|
| 1 | 吞异常 | `try: ... except Exception: log.warning(...); result = None` | 让它失败：`result = transform(data)` |
| 2 | 必填字段用 dict 默认值 | `user_id = record.get('user_id', -1)` | `user_id = record['user_id']` |
| 3 | 用 `or` 伪造数据 | `email = record.get('email') or 'no-email@example.com'` | 需要默认值时显式、文档化处理 |
| 4 | 类型强转代替校验 | `age = int(record.get('age', 0))` | 让类型不匹配暴露出来 |
| 5 | 兼容 shim | `try: new() except AttributeError: old()` | 强制迁移到新 API |
| 6 | 不必要的空检查 | `if user and user.name: return user.name` | 信任类型契约，直接 `return user.name` |
| 7 | 兜底异常 | `except: pass` | 捕获具体异常或让它传播 |
| 8 | 内部边界过度校验 | 每层函数都 `if data is None: return None` | 边界校验一次，内部信任 |
| 9 | 伪造默认值 | `created_at = record.get('created_at', datetime.now())` | 必填字段必须存在 |
| 10 | 只记警告不抛错 | `logger.warning(f"Unexpected state: {state}"); continue` | `raise ValueError(...)` |

**防御正确的位置（不要误报）：** 外部输入校验、用户错误提示、瞬时故障（网络超时/限流）、公共库。

## B. 过度工程

| 模式 | 触发标记 |
|------|---------|
| 过早抽象 | 为单一实现建 Factory/Strategy/抽象基类。"以后可能用得上。" |
| 无必要包装 | `get_config()` 只调 `os.environ.get()`。只被调用一次的 utility 函数。 |
| 过度模块化 | 简单逻辑拆到多个文件。小代码库建深层目录嵌套。 |

## C. 不必要基础设施

| 模式 | 触发标记 |
|------|---------|
| 到处重试 | 对本地函数调用或非瞬态操作做指数退避。 |
| 过度配置化 | 每个常量都可配置成环境变量（数学常量、格式串）。 |
| 无必要异步 | 对 CPU 密集或 <10ms 的快速操作用 asyncio/threading。 |
| 无理由特性开关 | 控制一个没有理由变化的行为的布尔开关。 |

## D. 代码膨胀

| 模式 | 触发标记 |
|------|---------|
| 过度日志 | 每个函数进出都 `logger.info`。记内部函数参数与返回值。 |
| 无意义常量提取 | `MAX_SIZE = 100` 而 100 上下文显而易见，不增加可读性。 |
| 废话 docstring | `def add(a, b): """Add a and b."""` —— 复述函数名。 |
| 无必要数据类 | 一次性使用还建 dataclass/TypedDict 而非 dict/tuple。 |

## E. 测试 Slop

| 模式 | 触发标记 |
|------|---------|
| 测了等于没测 | 断言函数存在或返回类型，而非返回正确值。无断言的测试。 |
| 过度 mock | mock 到只验证了 mock 本身而非真实逻辑。mock 掉要测的东西。 |

## F. 其他

| 模式 | 触发标记 |
|------|---------|
| 回调/事件滥用 | 简单线性流程用事件发射器、hook 系统或 pub/sub。 |
| 运行时类型检查 | 函数内 `isinstance` 重复类型提示 + 静态分析已覆盖的事。 |
| 幻觉导入 | 用错库版本的 API。导入不存在的包。 |
| 模板样板 | 为满足模板而非解决问题而存在的代码。空 `__init__.py` 配 docstring。 |
